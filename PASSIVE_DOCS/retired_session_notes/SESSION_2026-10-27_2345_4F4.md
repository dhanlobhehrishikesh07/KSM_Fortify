## What was done
- `index.html`: new panel `#ksm-syncpanel` ("ONLINE COPY") above the bridge log: last sync line, two buttons (`#ksm-sync-now`, `#ksm-sync-export`), a message line (`#ksm-sync-msg`, `role="status"`), and the note.

Last sync line says "nothing is sent online" when state is off, "not yet in this run" when no time, else the time. "Sync now" calls `api.sync_now()`, shows the backend `message` (all switches off) or "Sending started (kinds)", then refreshes the chip at once. "Export cloud data" calls `api.export_cloud_data()` and shows "Saved to: <path> (tasks: N, ...)" or "Export failed. <error>". A small `callSafely()` turns a missing method, a rejected call or a non-object answer into an error message; buttons are disabled while a call runs and always re-enabled. All text is set with `textContent` only.
- `style.css`: panel rules use theme variables only (`--good`, `--danger-bright`, `--warn-bright`, `--text1`, `--text2`).
