## What was asked
One small chip in the header showing Synced / Pending N / Offline / Off, refreshed on a timer from `get_sync_status`, using theme variables only.

## What was done
- `index.html`: new `<span id="ksm-syncchip">` in the top bar, next to the clock (starts as "Off").
- `app.js`: `refreshSyncChip()` calls `api.get_sync_status()` once at boot and then every 2 s (no overlapping calls). The chip shows the backend `label` (so "Pending 3"), sets `data-state` and a class, and a tooltip with the last sync time or the redacted last error (or "Nothing is sent online" when off). Text is set with `textContent` only. A failed call or a non-object answer shows "Unknown" in the Offline colour; an unknown state falls back to Off. The chip never throws.
- `style.css`: `.ksm-syncchip` and four state rules use only theme variables (`--good`, `--warn(-bright)`, `--danger(-bright)`, `--text2`, `--border`, `--bg-panel2`); no hard-coded colours.
- No Python change; `WebAPI` untouched.
